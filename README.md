# Portfolio (React + Vite)

Koyu temalı, animasyonlu kişisel portfolio sitesi.

## Kurulum

1. [Node.js](https://nodejs.org) (LTS) kurun.
2. Bu klasörde:

```bash
npm install
npm run dev
```

Tarayıcıda `http://localhost:5173` adresini açın. Yayın için `npm run build` → `dist/` klasörü.

## Özelleştirme

- **Tüm metinler / projeler / yetenekler:** `src/data.js`
- **Renkler ve fontlar:** `src/index.css` en üstteki `:root` değişkenleri (`--accent` vb.)
